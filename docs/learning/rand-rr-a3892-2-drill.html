Reading drill · RAND RR-A3892-2 · RAND Europe · June 25, 2026

AI agents put offensive cyber within reach of novices

Sperisen, Aguirre, van Soest, and Lopez compare 156 people using 2025 AI chatbots with Claude Code agents in 2026, on the same three hacking challenges. Read the drill, then explain the report back at the bottom.

Part 1

What the report says

Written in ASD-STE100 Simplified Technical English

What the researchers did

  1. First, RAND tested 156 people on three hacking challenges. The challenges are M1 (easy), M2 (medium), and M3 (hard).
  2. Half of the people used AI chatbots from August 2025. Half used no AI.
  3. Each person had 8 hours for each challenge.
  4. Then, in April 2026, RAND gave the same three challenges to Claude Code. Claude Code is an AI agent. It can run tools without help.
  5. RAND used two models: Sonnet 4.6 and Opus 4.6.
  6. The researchers did not give hacking help. They only restarted the agent when it stopped.

What they found

  1. The people with chatbots did not do much better than the people without AI.
  2. No person solved M2. Only one person solved M3.
  3. Claude Code solved all three challenges. Each one took less than 1 hour.
  4. All the runs together cost approximately 16 US dollars.
  5. The operator does not need hacking knowledge. The operator must only install the tool.
  6. One model used the work of the other model to get access faster.
  7. Thus, current risk tests are becoming out of date. Defenders must measure risk all the time.

Part 4

Terms, acronyms, and frameworks

Uplift
How much better a person does with AI than without it.

Like comparing your running time with and without good shoes.

RCT Randomised controlled trial
An experiment that splits people at random into a group that gets a tool and a group that doesn't.

Like a drug trial with a real pill and a sugar pill.

Statistically insignificant
The difference is too small to rule out chance.

Like winning 3 coin flips in a row. It doesn't prove the coin is rigged.

Agentic AI / AI agent
AI that plans and takes many steps on its own, using tools, instead of just answering questions.

Like hiring a contractor instead of calling a hotline for advice.

Chatbot
AI that answers in conversation. A person still has to do the work.

Like a cookbook that talks back, but you still cook.

Claude Code
Anthropic's agent that can run commands and write code on a computer.

Like a robot mechanic that can pick up the tools itself.

Subagents
Helper agents a main agent spawns for side tasks.

Like a general contractor sending out subcontractors.

Scaffolding
The software around a model that manages its tools, memory, and sessions. It caused most of the "hung" runs.

Like a car's transmission. A great engine still stalls if it fails.

API / Token
An API is how software calls the model. Tokens are the chunks of text the model reads and writes, and you pay per token.

Like a phone line, billed by the minute.

CTF Capture the flag
A hacking exercise where you break into a test machine to find a hidden secret.

Like an escape room for computers.

HTB / Pwnbox Hack The Box
A platform that hosts practice machines. Pwnbox is its ready-made attacker computer.

Like a climbing gym with rental gear.

Root / Root flag
Root is the all-powerful account on a Linux machine. The root flag proves you got it.

Like the master key to a building.

Reconnaissance nmap
Mapping what a target runs before attacking. Nmap is the standard scanning tool.

Like walking around a house and checking every door and window.

PCAP / Plaintext credentials
A PCAP is a recording of network traffic. Plaintext credentials are passwords stored or sent without encryption.

Like a recorded phone call where someone reads out their PIN.

SQL injection
Typing database commands into a form so the database obeys you.

Like writing "and give me the cash drawer" on a bank deposit slip.

SSRF Server-side request forgery
Tricking a server into fetching internal data for you.

Like asking a receptionist to grab a file from a back office you can't enter.

RCE Remote code execution
Running your own commands on someone else's machine over the network.

Like driving someone's car from across town.

Privilege escalation
Going from a limited account to a powerful one.

Like a visitor badge turned into a master key.

SUID / Linux capability
Settings that let a program run with more power than the user who starts it. Misconfigured, they hand out root.

Like a door that opens for anyone holding a manager's coffee mug.

SSH Secure Shell
An encrypted way to log in to a remote computer.

Like a locked tunnel into the building.

Piggy-back attack
Attacking through a door another attacker already opened.

Like a second burglar walking through a window the first one broke.

Attribution
Working out who carried out an attack.

Like a detective matching fingerprints, which is hard when two burglars used the same window.

Saturation (of a test)
When AI aces a test so easily that the test stops telling you anything.

Like giving a college student a 3rd-grade spelling quiz.

Active defenders / cyber range
A test environment where someone fights back, detecting and blocking the attacker.

Like a scrimmage against a real team instead of kicking at an empty goal.

UK AISI AI Security Institute
The UK government body that tests frontier AI models for safety risks.

Like a crash-test lab for AI.

Framework
Barrier to entry
The skill, time, and money needed before someone can do something. The report's core claim is that this barrier collapsed.

Like lock-picking going from years of practice to a $16 gadget.

Framework
Continuous risk measurement
Measuring risk on an ongoing basis instead of with one-time assessments that quickly go stale.

Like a fitness tracker versus a once-a-year physical.

Part 5

The core argument, for a beginner

In 2025, RAND asked a simple question: if you give ordinary people an AI chatbot, can they hack a computer? Mostly, no. People with chatbots did only slightly better than people without them, and almost nobody cracked the medium or hard challenges, even with eight hours each.

In 2026, RAND tried again with a different kind of AI: an agent that does the work itself instead of giving advice. Claude Code broke into all three machines, each in under an hour, for about $16 total. The humans running it only restarted it when it froze. They needed no hacking skill at all.

That is the jump: AI went from a tutor that didn't help much to a worker that does the whole job. So anyone who can install software can now attack an unpatched computer. The report also noticed something new: one AI picked up where another left off, which makes half-cleaned breaches dangerous and makes it harder to tell who attacked.

The conclusion is about how we measure risk. A study from 2025 was out of date by 2026. Practice hacking tests are becoming too easy to be useful. Defenders need to measure risk continuously, and tests need defenders who fight back.

Part 6

Read it critically, and connect it

Limits the authors state

  • Only three practice machines, with no defenders fighting back.
  • The two models ran at the same time and shared progress, so neither was tested alone.
  • It measures attack uplift only. It does not measure how much AI helps defenders.
  • The comparison isn't equal: people had a 2025 chatbot, the agent was a 2026 tool. The study shows the state of the art moved, not a clean head-to-head.
  • One M3 run used a likely unintended shortcut caused by a test-environment misconfiguration.

Why it matters for your NVD project

  • It raises the cost of slow warnings. If novices can exploit unpatched systems in under an hour, a 9-day gap before a KEV listing (PHP2Shell) means more attackers, not just faster experts.
  • It supports the scorecard directly. RAND says one-time risk assessments are becoming obsolete and calls for continuous measurement. A weekly NVD scorecard is that idea applied to the public warning system.
  • It argues for prediction over confirmation. When exploitation is cheap, waiting for confirmed attacks (KEV) is costlier. That strengthens the EPSS trigger.
  • Disclose it in your AI log. The study tested Anthropic models, and you used an Anthropic model to read it.
